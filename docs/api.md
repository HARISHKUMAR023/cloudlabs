
# Cloud Lab API

Base URL: `http://localhost:8000`

## Health

- **Method:** GET
- **Path:** `/health`

## Register

- **Method:** POST
- **Path:** `/api/v1/auth/register`

## Login

- **Method:** POST
- **Path:** `/api/v1/auth/login`

## Current User

- **Method:** GET
- **Path:** `/api/v1/users/me`
- **Authentication:** Bearer token required
